# Roadmap

## Phase 1: Prototype sandbox
- [ ] 1. Install Godot 4.3+ and create the project in `game/`, with a folder structure built for growth
- [ ] 2. Player: run, jump, roll, melee attack, health
- [ ] 3. Input layer: keyboard, gamepad, touch controls
- [ ] 4. Data-driven weapons (one resource per weapon), 2 to start
- [ ] 5. Enemy base class plus 2 or 3 simple types, data-driven
- [ ] 6. Sandbox test room with a menu to spawn enemies and swap weapons
- [ ] 7. Basic room-based level generation (random rooms plus an exit)
- [ ] 8. Export tests: Windows build, then web build hosted and tested on iPhone Safari

## Phase 2: Content (after the prototype is tested)
- [ ] 9. Boss framework, then many bosses with different styles
- [ ] 10. Equipment system and classes

## Phase 3: Story
- [ ] 11. Dialogue system
- [ ] 12. Quest system
