# A run, end to end (encounters, flask, cells and the shop)

Branch: `feature/runs`. Test builds: `/waves-1/`, `/flask-1/`, `/runs-1/` (the last has everything). Third and last port from the Graveflame review (MIT; ideas, our own numbers).

## The loop now
1. Walk into a middle room of a generated level: a **wave** appears (`WaveGenerator`).
2. The **exit gate is red and shut** until every enemy is dead.
3. Go through the gate: **pick one of three boons**, regain **one flask charge**, and the next level starts. **Health carries over** (no free heal per level).
4. Die: the **shop** opens. Spend **cells** on permanent upgrades, then DESCEND AGAIN: a new run (depth 0, boons dropped, shop upgrades applied).

## Pieces
- **Waves:** `WaveGenerator.roll(pool, depth, rng)`. Budget `4 + 2 x depth`; each enemy costs its `threat`; enemies unlock at `unlock_depth`; `max_per_wave` limits each kind; at most 6 per wave; never empty. Data on `EnemyData` (`threat`, `unlock_depth`, `max_per_wave`, `cell_reward`). Shambler: depth 0; Cinder Bat: depth 1; Crown Brute: depth 2, max 1.
- **Encounters:** `GeneratedLevel` triggers a room's wave when the hero is 3 tiles into it; seeded by level seed, room and depth. `encounters_enabled` turns this off for layout tests.
- **Flask:** FLASK button (touch, F, pad right-stick click). Committed 0.55s drink, heals 45 when it finishes; a hit spills it (no charge used). 3 charges per run; Witch's Flask boon adds one. `Player.enter_level` keeps health/flask; `Player.reset` restores health.
- **Cells and save:** `MetaSave` (static, JSON in `user://`, atomic writes, damaged-file fallback). Kills pay `cell_reward` (banked at once, so dying never loses them). Upgrades are `data/meta/*.tres` (`MetaUpgradeData`): Ember Soul, Sharpened, Quickened, Witch's Belt.
- **Shop:** `src/ui/meta_shop.gd`, opens on death, pauses the game. `Player.set_run_bonuses` applies the bought ranks at the start of every run.

## Notes
- On the web build the save lives in the browser's storage for the site, so clearing Safari data or using a different test-folder URL starts a fresh save.
- Tests point `MetaSave.path` at scratch files; they never touch a real save.

## To tune by playing
Wave budget growth, unlock depths, cell rewards and shop prices, flask heal (45) and charges (3), whether levels should be shorter or longer, whether the gate should also need rooms visited.
