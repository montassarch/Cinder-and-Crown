# Hero 3D stand-in model and animations

- Mannequin model and the sword, jump, hit and knockback clips: **Universal Animation Library 2** by Quaternius.
- Idle, sprint, jump, roll, hit and death clips: **Universal Animation Library** by Quaternius.
- License: CC0 1.0 (public domain). Credit is not required.
  https://quaternius.com/packs/universalanimationlibrary.html
  https://opengameart.org/content/universal-animation-library-2

`hero_model.scn` is built from the source files by keeping only the clips the game uses;
library 1's clips are authored at 1/100 scale, so their position keys are scaled by 100.
This is a stand-in until the hero gets his own 3D model on the same skeleton.
